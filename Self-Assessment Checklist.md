# Self-Assessment Checklist - Template (Five Safes and Ngā Tikanga Paihere)

> Use this checklist to confirm the required concepts in this portfolio.

## A) Five Safes — checklist

### SAFE 1 — Subject Matter
- [ ] Clear research purpose and objectives
- [ ] Mentions evaluation + scenario forecasting
- [ ] Explains why linked microdata is needed
- [ ] Includes public interest / public value statement
- [ ] Notes culturally safe and accountable interpretation approach (cross-reference)

### SAFE 2 — Legal
- [ ] States lawful/approved use of Stats NZ Data Lab microdata
- [ ] Includes Treaty of Waitangi / human rights responsiveness (via Ngā Tikanga Paihere)
- [ ] Mentions internal governance and compliance
- [ ] Includes auditability / documentation commitment

### SAFE 3 — Privacy
- [ ] Data minimisation described
- [ ] Non-disclosure / confidentiality protection described
- [ ] Mentions secure environment work only
- [ ] Addresses derived variables / intermediate outputs handling
- [ ] Mentions disclosure/risk controls at a high level

### SAFE 4 — Secure Outputs
- [ ] Export/disclosure controls described 
- [ ] Output review and approval process noted
- [ ] Responsible communication / uncertainty / limitations addressed
- [ ] Output documentation commitment included

### SAFE 5 — Safe People
- [ ] Training requirements stated (including any pathway requirements like required courses)
- [ ] Organisational governance roles described (sponsor/data governance/analysts)
- [ ] Advisory or capability support for culturally safe interpretation noted
- [ ] Mentions accountability documentation and responsiveness log
