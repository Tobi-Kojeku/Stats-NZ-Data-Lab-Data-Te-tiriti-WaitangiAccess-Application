# Stats NZ Data Lab — Mock Data Access Application 
This mock application is structured to demonstrate end-to-end compliance and responsiveness. The Five Safes are provided as separate sections (`five-safes/SAFE-*.md`) to show how the project handles subject matter, legal use, privacy, secure outputs, and safe people. Ngā Tikanga Paihere (`nga-tikanga-paihere/nga-tikanga-paihere.md`) explains how culturally safe interpretation and accountability are supported, and the `Responsiveness Log` template shows how engagement feedback would be documented and used in interpretation and communication decisions.


### The project topic:
Migration and Childbirth Outcomes in Aotearoa New Zealand: Evaluation and Scenario Forecasting Using Linked Microdata

### Study Period
- Last 10 years (2015 -2025)

### Key positioning
- This is written from a Research Institute perspective.
- Ethnicity/privacy-sensitive detail is kept minimal in this mock write-up.
- Migration definitions are generic (final definitions depend on Stats NZ Data Lab approved variables and linkage capability).
