# Data Access Request - Linked Microdata

## Requested access
We request access to linked microdata through the Stats NZ Data Lab suitable for analysis of:

1. **Childbirth / birth outcomes**  
   Variables needed to construct childbirth-related outcome metrics (as approved by Data Lab).

2. **Migration/residency indicators (generic)**  
   Variables sufficient to define migrant cohorts and/or relevant timing windows.  
   - Migration definitions will remain **generic** in this mock description.
   - The final operational definition will depend on available Data Lab variables and linkage capability.

3. **Population denominators / rate inputs**  
   Variables required to compute rates/indicators and support forecasting inputs.

## Intended linkage purpose
We request linkage that supports cohort/time-related analysis connecting migration/residency indicators to subsequent childbirth outcomes, subject to Stats NZ Data Lab-approved linkage capability and governance constraints.

If the requested linkage structure is not feasible, we will adapt analysis to the linkage setup that is approved while maintaining the study’s research purpose.

## Coverage
- Geography: New Zealand (both North and South Islands)
- Time period: last 10 years 

## Privacy and compliance commitments
- Data use limited to the approved research purpose.
- Outputs will follow Stats NZ Data Lab disclosure controls and review/approval steps.
- Any derived variables and intermediate outputs will be handled under Data Lab security requirements.
